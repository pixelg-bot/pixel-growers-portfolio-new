# Pixel Growers
React + TypeScript + Tailwind CSS + Framer Motion + Lucide React, built with Vite.

Run `npm install`, then `npm run dev`. Build with `npm run build`.

In VS Code, open **Terminal > Run Task** and choose **Portfolio: Start dev server** to run the site. Use **Portfolio: Production build** (also the default build task) to check types and create a production build. VS Code will recommend Tailwind CSS IntelliSense for class-name completion.

Graphik is bundled locally in `public/fonts` and is used throughout the portfolio. The Pixel Growers logo and favicon are in `public/branding`; partner badges used in the scrolling marquee are in `public/partners`. The About, team, company differentiators, worldwide work, service, portfolio, and testimonial sections use content adapted from the supplied company profile. Remote project imagery requires internet access. Contact details are from the profile; update them in `src/App.tsx` if they change.
